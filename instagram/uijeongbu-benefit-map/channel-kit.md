# 의정부 혜택지도 · 인스타그램 채널 키트 (초안 v0.1)

의정부를 동네 단위로 소개하면서, 시민이 놓치기 쉬운 지원금·할인·행사를 "지도처럼" 정리해 주는 채널입니다.
콘텐츠 형식은 의정부로컬비전(@ujb_localvision)을 참고합니다.

> 아직 @ujb_localvision 계정을 직접 보지 못했습니다(인스타그램 로그인 필요).
> 아래 형식은 일반적인 지역 소개 채널 기준의 가정이고, 캡처를 받으면 맞춰 고칩니다.

## 2. 콘텐츠 기둥 4개

| 기둥 | 형식 | 주기 | 목적 |
|---|---|---|---|
| A. 혜택 카드뉴스 | 캐러셀 6~8장 | 주 1회 (월) | 저장 유도 (나중에 신청하려고 저장) |
| B. 동네 탐방 | 릴스 20~30초 | 주 1회 | 조회수·신규 유입 (로컬비전식 동네 소개) |
| C. 혜택 지도 핀 | 캐러셀 또는 릴스 | 격주 | "우리 동네에서 쓰는 혜택" (가맹점, 할인 매장 등) |
| D. 이번 달 행사 | 캐러셀 1장 + 스토리 | 월 1회 | 공유 유도 (친구 태그) |

**운영 원칙**
- **모든 혜택 게시물에 기준일과 출처를 적는다.** 예: "2026.10.09 기준, 출처: 의정부시청 공고"
- **확인 안 된 금액·조건은 올리지 않는다.** 지원 사업은 해마다 조건이 바뀝니다.
- **마감된 사업은 "마감" 표시를 하거나 보관 처리한다.**
- 확인처: 의정부시청 공지·고시공고, 온통청년, 복지로, 경기지역화폐 앱

## 3. 첫 9개 게시물 (그리드 3x3)

계정을 열었을 때 보이는 첫 화면입니다. 위 줄이 가장 최근 게시물입니다.

| 순서 | 기둥 | 주제 | 상태 |
|---|---|---|---|
| 1 | 소개 | "의정부 혜택지도를 시작합니다" 채널 소개 캐러셀 | 바로 제작 가능 |
| 2 | A | 의정부 청년이 받을 수 있는 혜택 총정리 | 금액 최신 확인 필요 |
| 3 | B | 동네 탐방 #1: 의정부역 일대 | 촬영 필요 |
| 4 | A | 의정부사랑카드 기본 사용법 (충전, 인센티브, 쓰는 곳) | 2026년 인센티브율 확인 필요 |
| 5 | D | 10~11월 의정부 행사 모음 | 일정 확인 필요 |
| 6 | B | 동네 탐방 #2: 행복로·제일시장 | 촬영 필요 |
| 7 | C | 제일시장에서 지역화폐 쓰는 법 | 가맹 여부 현장 확인 |
| 8 | A | 이사 온 청년이라면: 중개수수료·이사비 지원 | 2026년 모집 마감(3/31), 내년 재공고 알림용 |
| 9 | B | 동네 탐방 #3: 민락동 | 촬영 필요 |

### 확인된 사실 (게시물 2, 8에 사용)
- **의정부시 청년 중개수수료·이사비 지원(2026):** 19~39세, 2025.1.1 이후 의정부 전입 또는 관내 이사 후 전입신고. 1인 최대 40만 원(생애 1회), 중개보수 최대 30만 원, 이사비 최대 40만 원(실지출 기준). 신청 기간 2026.2.23~3.31로 **이미 마감**.
  출처: 헤럴드K 2026.02.18
- **의정부사랑카드:** 명절 기간 할인율을 7%에서 10%로 올린 사례(2025.1 기사)가 있음. **2026년 현재 인센티브율과 한도는 확인되지 않음.**
  출처: 쿠키뉴스 2025.01.13

## 4. 게시물 1번 원고: 채널 소개 캐러셀 (6장)

| 장 | 화면 문구 |
|---|---|
| 1 (표지) | 의정부 살면서<br>이거 몰랐다면 손해📍 |
| 2 | 지원금, 지역화폐, 할인, 행사<br>다 따로 찾기 귀찮죠 |
| 3 | 그래서 동네별로<br>한 장에 모았습니다 |
| 4 | 매주 월요일<br>이번 주 마감 혜택 |
| 5 | 매주 한 번<br>우리 동네 탐방 릴스 |
| 6 | 저장해 두고<br>필요할 때 꺼내 보세요 |

### 캡션
```
의정부 살면서 받을 수 있는 혜택, 생각보다 많습니다.
문제는 다 따로 흩어져 있다는 것.

의정부 혜택지도는
✔️ 지원금·지역화폐·할인 정보를 동네별로 정리하고
✔️ 매주 월요일 마감 임박 혜택을 알려 드리고
✔️ 의정부 구석구석을 직접 다녀와서 소개합니다

궁금한 혜택이 있으면 댓글로 남겨 주세요. 다음 카드뉴스로 정리해 드릴게요.

※ 시민이 운영하는 비공식 채널입니다. 신청 전 의정부시청 공고를 꼭 확인하세요.

#의정부 #의정부혜택 #의정부생활
```

## 5. 릴스 기본 틀: 동네 탐방 (20~30초)

```
0:00-0:02  후크   화면: "의정부 ○○동, 여기 모르면 손해"
                  말:   "의정부 ○○동 사는데 여기 몰랐다고요?"
0:02-0:07  이유   이 동네에서만 쓸 수 있는 것 한 가지 (가게, 공원, 혜택)
0:07-0:22  본문   장소 3곳, 한 컷에 한 곳, 컷마다 화면 자막 6단어 이내
0:22-0:27  마무리 "저장해 두고 주말에 가 보세요" + 첫 장면 단어 반복(루프)
```
- 자막은 화면 위쪽~가운데 안전 영역에만 (아래쪽은 캡션에 가려짐)
- 실제 대본은 촬영 장소가 정해지면 `/ig-reel`로 후크 점수를 매겨 확정
