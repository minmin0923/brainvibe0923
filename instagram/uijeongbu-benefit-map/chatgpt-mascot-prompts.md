# 핀이 캐릭터 · ChatGPT 이미지 프롬프트

ChatGPT 앱(또는 chatgpt.com)에 아래 프롬프트를 **하나씩** 붙여 넣으면 됩니다.
마음에 드는 그림이 나오면 같은 대화에서 "이 캐릭터 그대로, 표정만 ○○로" 식으로 이어서 고치면 캐릭터가 유지됩니다.

## 공통 조건 (모든 프롬프트에 이미 들어 있음)
- 대표색 진초록 `#0F6E5C` + 노랑 포인트
- 한국 인스타 웹툰풍, 굵은 검정 외곽선, 단색 채색, 그라데이션 없음, 흰 배경
- 글자 없음 (₩ 기호만 허용)
- 의정부로컬비전 캐릭터(흰 둥근 몸 + 파란 삼각형)와 겹치지 않게

## 1. 추천안: 핀 머리 + 팔다리 (A안과 B안 합치기)
```
인스타그램 지역 정보 채널 "의정부 혜택지도"의 오리지널 마스코트 캐릭터 시트를 그려줘.
머리는 뒤집힌 물방울 모양의 지도 핀(위는 둥글고 아래로 뾰족)이고 진초록(#0F6E5C)이야. 머리 안쪽 둥근 부분에 흰 얼굴, 까만 점 눈, 작은 웃는 입, 노란 볼터치.
몸은 머리보다 작은 2등신으로, 짧고 통통한 팔다리가 있고 몸통도 진초록이야. 배에 작은 금색 ₩ 동전 무늬, 노란 운동화.
한국 인스타 웹툰 스타일, 굵은 검정 외곽선, 단색 채색, 그라데이션 없음, 흰 배경, 글자 없음.
가로로 4가지 포즈: 정면 미소 / 손가락으로 위를 가리키며 신남 / 깜짝 놀라 땀방울 / 바닥에 주저앉아 우는 모습.
```

## 2. 2등신 사람 가이드 (C안)
```
인스타그램 지역 정보 채널 "의정부 혜택지도"의 오리지널 마스코트 캐릭터 시트를 그려줘.
2등신 꼬마 동네 가이드: 큰 둥근 머리, 짧은 까만 머리, 진초록(#0F6E5C) 후드티 가슴에 노란 지도 핀 로고, 동전이 살짝 보이는 크로스백, 운동화.
점 눈과 표정 풍부한 눈썹. 한국 밈 인스타 계정에서 쓰는 코믹 웹툰 스타일, 굵은 검정 외곽선, 단색 채색, 흰 배경, 글자 없음.
가로로 4가지 포즈: 엄지척 / 뭔가를 가리키며 의기양양 / 입 크게 벌리고 충격 / 지갑이 텅 비어 허탈.
```

## 3. 핀 깃발 든 병아리 (D안)
```
인스타그램 지역 정보 채널 "의정부 혜택지도"의 오리지널 마스코트 캐릭터 시트를 그려줘.
작고 동그란 노란 병아리가 진초록(#0F6E5C) 탐험가 모자를 쓰고, 자기 키만 한 진초록 지도 핀을 깃발처럼 등에 메고 있어. 허리에 ₩ 표시가 있는 작은 금색 동전 주머니.
까만 점 눈, 주황 부리, 분홍 볼터치. 한국 인스타 웹툰 스티커 스타일, 굵은 검정 외곽선, 단색 채색, 흰 배경, 글자 없음.
가로로 4가지 포즈: 땅에 핀을 꽂으며 뿌듯 / 금화를 번쩍 들고 기쁨 / 깃털이 부풀며 깜짝 / 지도를 거꾸로 들고 갸우뚱.
```

## 4. 접힌 지도 캐릭터
```
인스타그램 지역 정보 채널 "의정부 혜택지도"의 오리지널 마스코트 캐릭터 시트를 그려줘.
몸 전체가 세 번 접힌 종이 지도인 캐릭터. 지도 면에는 초록 공원과 파란 강, 몸 한가운데에 진초록(#0F6E5C) 지도 핀이 꽂혀 있어. 지도 위쪽 칸에 큰 점 눈과 웃는 입, 노란 볼터치. 가느다란 팔다리, 노란 운동화.
한국 인스타 웹툰 스타일, 굵은 검정 외곽선, 단색 채색, 흰 배경, 글자 없음.
가로로 4가지 포즈: 지도 몸을 활짝 펼치며 인사 / 몸에 꽂힌 핀을 자랑 / 바람에 펄럭이며 당황 / 반으로 접혀 졸고 있음.
```

## 5. 동전 캐릭터 + 핀 모자
```
인스타그램 지역 정보 채널 "의정부 혜택지도"의 오리지널 마스코트 캐릭터 시트를 그려줘.
통통한 금색 동전(가운데 ₩ 기호) 몸을 가진 캐릭터가 진초록(#0F6E5C) 지도 핀 모양 모자를 쓰고 있어. 동전 테두리는 진한 노랑, 짧은 초록 팔다리.
까만 점 눈, 장난스러운 웃음. 한국 인스타 웹툰 스티커 스타일, 굵은 검정 외곽선, 단색 채색, 흰 배경, 글자 없음.
가로로 4가지 포즈: 윙크하며 엄지척 / 데굴데굴 굴러가며 신남 / 반짝이며 자랑 / 돈 아까워서 우는 모습.
```

## 6. 프로필 사진용 단독 아이콘 (어느 안이든 정한 뒤)
```
방금 그린 캐릭터를 인스타그램 프로필 사진용으로 다시 그려줘.
정사각형, 캐릭터 얼굴과 상반신만 크게, 가운데 정렬, 연한 민트색 원형 배경, 손가락으로 브이. 작은 원으로 잘려도 알아볼 수 있게 단순하게. 글자 없음.
```

## 고를 때 기준
1. 프로필 사진 크기(작은 원)로 줄여도 알아보는가
2. 우는 모습, 놀라는 모습 같은 상황극 연기가 되는가
3. 보자마자 "지도"나 "혜택"이 떠오르는가
4. 의정부로컬비전 캐릭터와 헷갈리지 않는가

# 2차: 더 귀엽고 세련되게 (요소 줄이기)

1차 시안이 부족했던 이유: 동전·운동화·볼터치·굵은 선·진한 색을 한꺼번에 넣어 복잡해짐.
원칙: 모양 하나로 승부, 머리 크게, 눈·입은 작게 아래로, 민트 + 크림 두 색, 얇은 진회색 선 또는 선 없음.

## 7. 말랑 핀 (추천)
```
미니멀하고 귀여운 오리지널 마스코트 캐릭터를 그려줘.
작은 지도 핀 모양의 캐릭터야. 위는 동그랗고 아래로 갈수록 살짝 뾰족하지만, 전체적으로 말랑한 젤리처럼 둥글둥글해.
색은 부드러운 민트 그린 한 가지, 얼굴 부분만 크림색 원. 얼굴 아래쪽에 아주 작은 까만 점 눈 두 개와 작은 입. 팔은 아주 짧은 콩알 모양, 다리는 없음.
얇고 둥근 진회색 외곽선, 단색 채색, 그림자 없음, 그라데이션 없음.
일본·한국 캐릭터 굿즈 브랜드처럼 깔끔하고 세련된 스타일. 연한 아이보리 배경, 글자 없음.
가로로 4가지 표정: 기본 / 눈을 감고 웃음(^^) / 놀람(동그란 눈) / 시무룩(눈물 한 방울).
```

## 8. 핀 모자 쓴 작은 아이
```
미니멀하고 귀여운 오리지널 마스코트 캐릭터를 그려줘.
크림색의 작고 동그란 찹쌀떡 같은 몸, 머리가 몸보다 큰 1.5등신. 머리 위에 민트 그린 지도 핀이 작은 모자처럼 살짝 기울어져 얹혀 있어.
얼굴은 아래쪽에 작은 점 눈 두 개, 아주 작은 입, 연한 분홍 볼 하나씩. 팔다리는 짧은 콩알 모양.
얇고 둥근 진회색 외곽선, 단색 채색, 그림자 없음. 깔끔하고 세련된 캐릭터 굿즈 스타일, 연한 아이보리 배경, 글자 없음.
가로로 4가지 포즈: 정면 서기 / 한 손 들고 인사 / 핀 모자를 손으로 잡고 뛰어가기 / 앉아서 졸기.
```

## 9. 선 없는 플랫 아이콘형
```
미니멀한 오리지널 마스코트 캐릭터를 그려줘.
외곽선 없이 단순한 도형만으로 만든 플랫 일러스트. 동그란 머리와 아래로 뾰족한 꼬리가 이어진 지도 핀 실루엣, 색은 민트 그린 한 가지.
얼굴에는 까만 점 눈 두 개와 작은 곡선 입만 있음. 아주 짧은 팔.
현대적인 앱 마스코트처럼 깔끔하고 세련된 느낌, 그림자·질감·그라데이션 없음, 연한 아이보리 배경, 글자 없음.
가로로 4가지 표정: 기본 / 윙크 / 놀람 / 하트 눈.
```

# 3차: 8번(핀 모자 쓴 작은 아이) + 의정부 상징

사용자 선택: 8번. 아래는 **8번을 만든 같은 대화창**에 이어서 붙여 넣는 수정 프롬프트입니다.

| 상징 | 쓰는 법 | 비고 |
|---|---|---|
| 부대찌개 | 냄비 크로스백 (대표 소품) | 전국 인지도 |
| 철쭉 (시화) | 핀 모자에 꽃 한 송이 (고정) | 공식 상징물 |
| 경전철 | 콘텐츠용 탈것 | 지역 인지도 |
| 조선 관모 | 쓰지 않음 | 공식 마스코트 "의돌이"(정승)와 겹침 |

## 10. 추천: 철쭉 + 부대찌개 냄비 가방
```
방금 캐릭터 그대로 유지하고 두 가지만 추가해줘.
1) 머리 위 민트 지도 핀 모자 옆에 작은 분홍 철쭉꽃 한 송이를 꽂아줘.
2) 작은 부대찌개 냄비 모양의 크로스백을 메게 해줘. 양손잡이 달린 낮은 냄비, 뚜껑 위로 라면 면발과 햄 한 조각이 살짝 보이게. 냄비 색은 연한 주황.
나머지(몸 비율, 얼굴, 선 굵기, 색, 아이보리 배경)는 바꾸지 마. 글자 없음.
가로로 4가지 포즈: 정면 서기 / 한 손 들고 인사 / 냄비 가방을 열어 자랑 / 앉아서 졸기.
```

## 11. 경전철 버전 (콘텐츠용)
```
같은 캐릭터 그대로, 이번엔 의정부 경전철을 함께 그려줘.
작고 동글동글한 2량짜리 무인 경전철 장난감 같은 모양, 흰색 차체에 민트 줄무늬. 캐릭터가 경전철 맨 앞 창문에서 얼굴을 내밀고 손을 흔드는 장면.
캐릭터 모습, 선, 색, 아이보리 배경은 그대로. 글자 없음.
```

## 12. 프로필 사진용
```
같은 캐릭터를 인스타그램 프로필 사진용으로 그려줘.
정사각형, 얼굴과 철쭉 꽂은 핀 모자가 크게 보이게 상반신만, 가운데 정렬, 연한 민트 원형 배경. 작은 원으로 잘려도 알아보게 단순하게. 글자 없음.
```
