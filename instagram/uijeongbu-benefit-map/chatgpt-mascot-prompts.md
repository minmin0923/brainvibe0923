# 핀이 캐릭터 · ChatGPT 이미지 프롬프트

ChatGPT 앱(또는 chatgpt.com)에 아래 프롬프트를 **하나씩** 붙여 넣으면 됩니다.
마음에 드는 그림이 나오면 같은 대화에서 "이 캐릭터 그대로, 표정만 ○○로" 식으로 이어서 고치면 캐릭터가 유지됩니다.

## 공통 조건 (모든 프롬프트에 이미 들어 있음)
- 대표색 진초록 `#0F6E5C` + 노랑 포인트
- 한국 인스타 웹툰풍, 굵은 검정 외곽선, 단색 채색, 그라데이션 없음, 흰 배경
- 글자 없음 (₩ 기호만 허용)
- 의정부로컬비전 캐릭터(흰 둥근 몸 + 파란 삼각형)와 겹치지 않게

---

## 1. 추천안: 핀 머리 + 팔다리 (A안과 B안 합치기)
```
인스타그램 지역 정보 채널 "의정부 혜택지도"의 오리지널 마스코트 캐릭터 시트를 그려줘.
머리는 뒤집힌 물방울 모양의 지도 핀(위는 둥글고 아래로 뾰족)이고 진초록(#0F6E5C)이야. 머리 안쪽 둥근 부분에 흰 얼굴, 까만 점 눈, 작은 웃는 입, 노란 볼터치.
몸은 머리보다 작은 2등신으로, 짧고 통통한 팔다리가 있고 몸통도 진초록이야. 배에 작은 금색 ₩ 동전 무늬, 노란 운동화.
한국 인스타 웹툰 스타일, 굵은 검정 외곽선, 단색 채색, 그라데이션 없음, 흰 배경, 글자 없음.
가로로 4가지 포즈: 정면 미소 / 손가락으로 위를 가리키며 신남 / 깜짝 놀라 땀방울 / 바닥에 주저앉아 우는 모습.
```

## 2. 2등신 사람 가이드 (C안)
```
인스타그램 지역 정보 채널 "의정부 혜택지도"의 오리지널 마스코트 캐릭터 시트를 그려줘.
2등신 꼬마 동네 가이드: 큰 둥근 머리, 짧은 까만 머리, 진초록(#0F6E5C) 후드티 가슴에 노란 지도 핀 로고, 동전이 살짝 보이는 크로스백, 운동화.
점 눈과 표정 풍부한 눈썹. 한국 밈 인스타 계정에서 쓰는 코믹 웹툰 스타일, 굵은 검정 외곽선, 단색 채색, 흰 배경, 글자 없음.
가로로 4가지 포즈: 엄지척 / 뭔가를 가리키며 의기양양 / 입 크게 벌리고 충격 / 지갑이 텅 비어 허탈.
```

## 3. 핀 깃발 든 병아리 (D안)
```
인스타그램 지역 정보 채널 "의정부 혜택지도"의 오리지널 마스코트 캐릭터 시트를 그려줘.
작고 동그란 노란 병아리가 진초록(#0F6E5C) 탐험가 모자를 쓰고, 자기 키만 한 진초록 지도 핀을 깃발처럼 등에 메고 있어. 허리에 ₩ 표시가 있는 작은 금색 동전 주머니.
까만 점 눈, 주황 부리, 분홍 볼터치. 한국 인스타 웹툰 스티커 스타일, 굵은 검정 외곽선, 단색 채색, 흰 배경, 글자 없음.
가로로 4가지 포즈: 땅에 핀을 꽂으며 뿌듯 / 금화를 번쩍 들고 기쁨 / 깃털이 부풀며 깜짝 / 지도를 거꾸로 들고 갸우뚱.
```

## 4. 접힌 지도 캐릭터
```
인스타그램 지역 정보 채널 "의정부 혜택지도"의 오리지널 마스코트 캐릭터 시트를 그려줘.
몸 전체가 세 번 접힌 종이 지도인 캐릭터. 지도 면에는 초록 공원과 파란 강, 몸 한가운데에 진초록(#0F6E5C) 지도 핀이 꽂혀 있어. 지도 위쪽 칸에 큰 점 눈과 웃는 입, 노란 볼터치. 가느다란 팔다리, 노란 운동화.
한국 인스타 웹툰 스타일, 굵은 검정 외곽선, 단색 채색, 흰 배경, 글자 없음.
가로로 4가지 포즈: 지도 몸을 활짝 펼치며 인사 / 몸에 꽂힌 핀을 자랑 / 바람에 펄럭이며 당황 / 반으로 접혀 졸고 있음.
```

## 5. 동전 캐릭터 + 핀 모자
```
인스타그램 지역 정보 채널 "의정부 혜택지도"의 오리지널 마스코트 캐릭터 시트를 그려줘.
통통한 금색 동전(가운데 ₩ 기호) 몸을 가진 캐릭터가 진초록(#0F6E5C) 지도 핀 모양 모자를 쓰고 있어. 동전 테두리는 진한 노랑, 짧은 초록 팔다리.
까만 점 눈, 장난스러운 웃음. 한국 인스타 웹툰 스티커 스타일, 굵은 검정 외곽선, 단색 채색, 흰 배경, 글자 없음.
가로로 4가지 포즈: 윙크하며 엄지척 / 데굴데굴 굴러가며 신남 / 반짝이며 자랑 / 돈 아까워서 우는 모습.
```

## 6. 프로필 사진용 단독 아이콘 (어느 안이든 정한 뒤)
```
방금 그린 캐릭터를 인스타그램 프로필 사진용으로 다시 그려줘.
정사각형, 캐릭터 얼굴과 상반신만 크게, 가운데 정렬, 연한 민트색 원형 배경, 손가락으로 브이. 작은 원으로 잘려도 알아볼 수 있게 단순하게. 글자 없음.
```

## 고를 때 기준
1. 프로필 사진 크기(작은 원)로 줄여도 알아보는가
2. 우는 모습, 놀라는 모습 같은 상황극 연기가 되는가
3. 보자마자 "지도"나 "혜택"이 떠오르는가
4. 의정부로컬비전 캐릭터와 헷갈리지 않는가
