# 에이전트 기억 (MEMORY)

## 사용자 선호

- 한국어로 보고한다. 쉬운 말로, 결론부터.
- 화면 작업은 `DESIGN.md`가 기준이다.
- Codex 검토는 하지 않는다(2026-11-10 지시, OpenAI 크레딧 없음). 사용자가 다시 켜라고 할 때까지 Claude가 스스로 검토한다.

## 이 저장소에서 통하는 방법

- 문서, 발표, 대시보드는 `templates/`의 양식에서 시작한다.
