# 에이전트 모드

정해진 시간(한국 시간 08:47, 14:47, 20:47)마다 전용 세션 "에이전트 본부"가 깨어나 명령함을 확인하고, 일을 처리하고, 배운 것을 기록하는 자동 작업 방식이다.

## 명령 내리기

가장 쉬운 방법은 **관제실**이다: https://claude.ai/artifact/PhVkovV8DEeonV949DC6qF
할 일을 적어 보내면 에이전트를 바로 깨우고, 담당별 진행 과정과 결과, 에이전트가 먼저 보낸 알림이 같은 화면에 쌓인다. 화면 원본은 `agent/console.html`.

| 방법 | 어떻게 |
|---|---|
| 명령어 | Claude 세션에서 `/console` 또는 `/관제실`. 뒤에 할 일을 붙이면 바로 지시로 들어간다. 예: `/console README 정리해 줘` |
| 관제실 | 위 주소에서 "새 지시"에 적고 "지시 보내기". |
| GitHub 이슈 | 제목을 `[에이전트]`로 시작해 이슈를 만든다. 휴대폰 GitHub 앱에서도 된다. |
| 명령함 파일 | `agent/INBOX.md`의 "할 일"에 `- [ ] ...` 한 줄을 더한다. |
| Claude 세션 | 아무 세션에서 "에이전트에게 시켜: ..."라고 말하면 명령함에 넣어 준다. 급하면 "지금 에이전트 실행해"라고 한다. |

## 감독하기

- **감독 창:** Claude 세션에서 `/agent-panel`을 입력하면 채팅 옆에 창이 열린다. 기다리는 명령, 작업 중인 브랜치, 최근 일지를 보여 준다. 다시 입력하면 닫힌다.
- **실시간:** Claude 앱의 세션 목록에서 "에이전트 본부" 세션을 열면 에이전트가 하는 일을 그대로 볼 수 있고, 거기에 직접 말해서 지시하거나 멈출 수도 있다.
- **결과:** 모든 변경은 제목이 `[에이전트]`로 시작하는 PR로 온다. 병합하면 승인, 닫으면 거절이다. 리뷰 댓글을 남기면 다음 실행에서 고친다.
- **일지:** `agent/LOG.md`에 실행마다 한 일이 적힌다.
- **기억:** `agent/MEMORY.md`에 배운 것이 쌓인다. 틀린 내용은 직접 고치면 된다.
- **멈추기:** Claude 세션에서 "에이전트 멈춰"라고 하면 예약을 끈다.

## 텔레그램으로 결과 받기

1. 텔레그램에서 `@BotFather`에게 `/newbot`을 보내 봇을 만들고 토큰을 받는다.
2. 만든 봇과의 대화방에서 아무 말이나 한 번 보낸다. 그다음 `@userinfobot`에게 말을 걸어 내 번호(Id)를 확인한다. 단체방으로 받으려면 봇을 단체방에 넣고 그 방의 번호를 쓴다.
3. GitHub 저장소 Settings > Secrets and variables > Actions 에서 비밀값 두 개를 만든다: `TELEGRAM_BOT_TOKEN`(토큰), `TELEGRAM_CHAT_ID`(번호).
4. 관제실 위쪽의 "텔레그램 전송" 스위치를 켠다.

토큰은 GitHub 비밀값에만 넣는다. 채팅이나 파일에 적지 않는다. 전송은 `.github/workflows/telegram-send.yml`이 맡는다.

## 배우고 업그레이드하는 방식

- 실행이 끝날 때 사용자의 수정 요청, 거절된 PR, 반복된 실수에서 교훈을 뽑아 `MEMORY.md`에 적고, 다음 실행은 그것부터 읽는다.
- 같은 문제가 반복되면 자기 규칙(`RUNBOOK.md`, 스킬, 스크립트)을 고치는 `[에이전트][개선]` PR을 올린다. 병합해야 적용된다.
- AI 모델 자체가 다시 학습되는 것은 아니다. 기록과 규칙이 쌓여서 나아지는 방식이다.

## 하지 않는 일

기본 브랜치 직접 푸시, PR 자체 병합, 결제, 외부 발송, 삭제, 비밀키 읽기. 자세한 내용은 `agent/RUNBOOK.md` 0절.
