# 에이전트 모드

정해진 시간마다 스스로 깨어나 명령함을 확인하고, 일을 처리하고, 배운 것을 기록하는 자동 작업 방식이다.

## 명령 내리기

| 방법 | 어떻게 |
|---|---|
| GitHub 이슈 | 제목을 `[에이전트]`로 시작해 이슈를 만든다. 휴대폰 GitHub 앱에서도 된다. |
| 명령함 파일 | `agent/INBOX.md`의 "할 일"에 `- [ ] ...` 한 줄을 더한다. |
| Claude 세션 | 아무 세션에서 "에이전트에게 시켜: ..."라고 말하면 명령함에 넣어 준다. 급하면 "지금 에이전트 실행해"라고 한다. |

## 감독하기

- **결과:** 모든 변경은 제목이 `[에이전트]`로 시작하는 PR로 온다. 병합하면 승인, 닫으면 거절이다. 리뷰 댓글을 남기면 다음 실행에서 고친다.
- **일지:** `agent/LOG.md`에 실행마다 한 일이 적힌다.
- **기억:** `agent/MEMORY.md`에 배운 것이 쌓인다. 틀린 내용은 직접 고치면 된다.
- **멈추기:** Claude 세션에서 "에이전트 멈춰"라고 하면 예약을 끈다.

## 배우고 업그레이드하는 방식

- 실행이 끝날 때 사용자의 수정 요청, 거절된 PR, 반복된 실수에서 교훈을 뽑아 `MEMORY.md`에 적고, 다음 실행은 그것부터 읽는다.
- 같은 문제가 반복되면 자기 규칙(`RUNBOOK.md`, 스킬, 스크립트)을 고치는 `[에이전트][개선]` PR을 올린다. 병합해야 적용된다.
- AI 모델 자체가 다시 학습되는 것은 아니다. 기록과 규칙이 쌓여서 나아지는 방식이다.

## 하지 않는 일

기본 브랜치 직접 푸시, PR 자체 병합, 결제, 외부 발송, 삭제, 비밀키 읽기. 자세한 내용은 `agent/RUNBOOK.md` 0절.
