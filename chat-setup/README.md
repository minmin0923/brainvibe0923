# Claude 채팅(claude.ai)에서 쓰기

Claude Code용으로 설치한 디자인 도구를 Claude 채팅에서도 쓰기 위한 준비물입니다.

## 들어 있는 것

| 파일 | 용도 |
|---|---|
| `design-taste-frontend.zip` | AI 티 안 나는 화면 디자인 스킬 |
| `image-to-code.zip` | 참고 이미지를 화면 코드로 옮기는 스킬 |
| `web-design-guidelines.zip` | 접근성과 사용성 점검 스킬 |
| `프로젝트-지침.md` | 채팅 프로젝트의 지침란에 붙여 넣을 문장 |

`agent-browser`는 명령어를 실행해야 하는 도구라 채팅에서는 쓸 수 없어서 넣지 않았습니다.

## 설정 순서

1. **스킬 올리기:** claude.ai 설정에서 Skills 항목을 찾아 zip 파일 세 개를 하나씩 올리고 켭니다. (메뉴 이름과 위치는 바뀔 수 있습니다. 코드 실행 기능이 켜져 있어야 스킬이 작동합니다.)
2. **프로젝트 만들기:** 채팅 왼쪽의 Projects에서 새 프로젝트를 만듭니다. 이름 예: "디자인 작업".
3. **기준 파일 넣기:** 프로젝트 지식(파일)에 저장소 맨 위의 `DESIGN.md`를 올립니다.
4. **지침 붙여 넣기:** `프로젝트-지침.md`의 "붙여 넣을 내용" 부분을 프로젝트 지침란에 그대로 붙여 넣습니다.
5. 이후 화면 작업은 이 프로젝트 안에서 대화를 시작합니다.

## 주의

- `DESIGN.md`를 고치면 채팅 프로젝트에 올린 파일도 새로 올려야 반영됩니다.
- 스킬이 업데이트되면 zip을 다시 만들어 올려야 합니다. (`.claude/skills`의 폴더를 그대로 zip으로 묶으면 됩니다.)
- `image-to-code`는 원래 이미지를 직접 생성하는 환경을 기준으로 쓰였습니다. 채팅에서는 참고 이미지나 스크린샷을 직접 올려서 쓰는 것이 가장 잘 맞습니다.
