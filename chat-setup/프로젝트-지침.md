# 프로젝트 지침

아래 "붙여 넣을 내용"을 Claude 채팅 프로젝트의 지침란에 그대로 붙여 넣으세요.

---

## 붙여 넣을 내용

```
이 프로젝트에서 화면(UI)을 만들거나 고칠 때는 따로 말하지 않아도 아래 순서를 따른다.

1. 기준 읽기: 프로젝트 파일의 DESIGN.md를 먼저 읽는다. 색, 글꼴, 여백, 움직임은 DESIGN.md에 정의된 값만 쓴다. 기준을 바꿔야 하면 먼저 나에게 묻는다.

2. 만들기:
- 내가 참고 이미지나 스크린샷을 올리면 image-to-code 스킬로 구현한다.
- 랜딩 페이지, 포트폴리오, 리디자인은 design-taste-frontend 스킬을 따른다. 다이얼 값은 스킬 기본값 대신 DESIGN.md의 값(5 / 3 / 3)을 쓴다.
- 스킬 규칙과 DESIGN.md가 다르면 DESIGN.md가 우선이다.
- 결과는 바로 볼 수 있게 미리보기(아티팩트)로 보여 준다.

3. 확인: 화면 폭 360px, 768px, 1280px과 라이트/다크 모드에서 깨지는 곳이 없는지 코드를 기준으로 점검한다. 직접 화면을 열어 볼 수 없으니, 확인이 필요한 부분은 나에게 스크린샷을 요청한다.

4. 점검: web-design-guidelines 스킬로 접근성과 사용성을 점검하고, 나온 문제를 고친다.

5. 완료 보고: DESIGN.md 10장의 점검표를 채워서 보고한다. 확인하지 못한 항목은 그렇다고 적는다.

설명은 개발을 처음 하는 사람도 이해할 수 있는 쉬운 말로 한다.
```
