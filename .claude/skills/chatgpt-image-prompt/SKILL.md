# ChatGPT 이미지 프롬프트

API 요금 없이 사용자의 ChatGPT 구독으로 이미지를 만든다. Claude는 프롬프트를 쓰고, 받은 이미지를 확인하고, 작업에 넣는다.

## 1. 프롬프트 쓰기

이미지마다 아래 형식으로 `generated/prompts/<이름>.md`에 저장하고, 같은 내용을 답변에도 코드 블록으로 보여 준다. `<이름>`은 영어 소문자와 하이픈으로 짓는다(예: `hero-coffee-desk`).

````markdown
# <이름>

- 쓰는 곳: (예: 랜딩 첫 화면 배경, 쇼츠 2번 장면)
- 비율: 가로 3:2 / 세로 2:3 / 정사각형 1:1
- 저장할 파일 이름: <이름>.png

## ChatGPT에 붙여 넣을 프롬프트

```
(영어 프롬프트)
```

## 고칠 때 이어서 쓸 말

- 더 밝게: "Make the lighting brighter and warmer, keep everything else the same."
- (예상되는 수정 요청 2~3개)
````

프롬프트 쓰는 법:

- 영어로, 한 덩어리 문장으로 쓴다. 주제 → 구도·카메라 → 조명 → 스타일·질감 → 색 → 분위기 → 비율 순서로 넣는다.
- 맨 끝에 비율을 문장으로 적는다. 예: "Wide 3:2 landscape image."
- 이미지 안에 들어갈 글자는 큰따옴표로 정확히 적고, 글자가 필요 없으면 "No text in the image."를 넣는다.
- 웹 화면에 쓸 이미지는 DESIGN.md의 강조색과 분위기를 색 설명에 반영한다.
- 여러 장이 같은 캐릭터·스타일이어야 하면, 공통 설명(캐릭터 외형, 화풍, 색)을 모든 프롬프트에 똑같이 넣는다.
- 한 번에 여러 장이 필요하면 장마다 파일을 따로 만든다.

## 2. 사용자에게 알릴 것

프롬프트를 준 뒤 이렇게 안내한다.

1. ChatGPT에 프롬프트를 붙여 넣어 만든다. 고칠 때는 "고칠 때 이어서 쓸 말"을 같은 대화에 이어서 쓴다.
2. 마음에 드는 이미지를 저장해서 이 대화에 첨부하거나, GitHub의 `generated/images/` 폴더에 `<이름>.png`로 올린다.

## 3. 이미지를 받으면

1. 대화에 첨부된 이미지는 `generated/images/<이름>.png`로 저장한다. GitHub에 올렸다면 `git pull`로 받는다.
2. Read로 열어 프롬프트대로 나왔는지 본다. 글자 오타, 손·얼굴 어색함, 비율, 잘린 부분을 확인한다.
3. 문제가 있으면 ChatGPT에 이어서 쓸 수정 문장을 영어로 써 준다.
4. 크기 조정, 자르기, 압축, 형식 변환처럼 단순한 편집은 Claude가 직접 한다(ffmpeg 또는 Python Pillow).
5. 쓰는 곳(페이지 assets, 영상 프로젝트)으로 복사하고 경로를 알려 준다.
