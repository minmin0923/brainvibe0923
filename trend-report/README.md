# AI 바이럴 주간 리포트

인스타그램에서 국내외로 퍼진 AI 콘텐츠를 1주 단위로 모으고, 왜 퍼졌는지 분석해서 보여주는 페이지입니다.
채널 만들기 1단계(자료 확인, 분석, 제시)에 해당합니다.

- 화면: `index.html`을 브라우저로 열면 됩니다. 서버가 필요 없습니다.
- 데이터: `data.js`의 `TREND_REPORTS` 배열. 맨 앞 항목이 최신 주차입니다.

## 매주 하는 일

1. **기간 정하기.** 리포트 작성일 기준 지난 7일.
2. **웹에서 후보 찾기.** 아래 출처를 훑고 AI로 만든 영상이나 AI 사진 트렌드만 고릅니다.
   - 해외: LADbible, Know Your Meme, Later 릴스 트렌드, lightreel 주간 리포트, TechRadar, Forbes
   - 국내: Trend A Word, 고구마팜, AI매터스 AI 트렌드, 인스타공백닷컴 밈 사전, 한국경제 등 [트렌드+] 기사
3. **인스타그램에서 직접 확인하기.** 이 저장소의 클라우드 작업 환경은 인스타그램 접속이 막혀 있어서, 이 단계는 앱에서 사람이 합니다.
   - 릴스 탭에서 `AI영상`, `AI릴스`, `챗GPT프롬프트`, `aivideo`, `aiart`, `aitrend` 검색
   - 후보 계정의 최근 릴스 조회수, 올린 날짜, 오디오 사용 수를 적습니다.
   - 각 사례의 "인스타그램에서 직접 확인할 것" 칸을 채웁니다.
4. **판정하기.** 아래 기준으로 상태와 근거를 정합니다.
5. **`data.js`에 추가하고** 화면에서 확인합니다.

## 바이럴 판정 기준

| 상태 | 뜻 |
|---|---|
| `peak` | 이번 주 안에 정점이 있었다는 보도나 수치가 있다 |
| `ongoing` | 이번 주 전에 시작했지만 이번 주에도 퍼지고 있다 |
| `reference` | 기간 밖이지만 우리 채널 포맷에 참고할 가치가 있다 |

| 근거 | 뜻 |
|---|---|
| `metric` | 조회수, 좋아요, 팔로워 같은 숫자를 출처에서 확인했다 |
| `press` | 매체나 리포트에서 퍼졌다고 했지만 숫자는 없다 |
| `unverified` | 날짜나 수치를 아직 확인하지 못했다 |

참고로 쓰는 숫자 기준(계정 크기에 따라 조정): 릴스 하나가 7일 안에 100만 회 이상, 또는 팔로워 수의 10배 이상 조회.

## 항목 작성 규칙

- 확인하지 못한 숫자는 적지 않습니다. 모르면 "확인 필요"라고 적습니다.
- 출처 링크를 최소 하나 넣습니다.
- `idea`에는 우리 채널에서 바로 만들 수 있는 한 문장을 적습니다.
- 실존 인물 얼굴, 영화 캐릭터처럼 권리 문제가 있는 요소는 `caution`에 적습니다.
- 문장은 짧게, 긴 줄표(—)는 쓰지 않습니다 (`DESIGN.md` 9장).

```js
  id: "jean-phil",              // 영문 소문자와 하이픈
  region: "global",             // kr | global | both

  evidence: "metric",           // metric | press | unverified
  title: "",
  account: "",
  type: "",                     // 예: AI 캐릭터 시리즈, 참여형 AI 사진
  firstSeen: "",
  peak: "",

  why: [""],                    // 왜 퍼졌나
  caution: "",
  idea: "",                     // 우리 채널에서 만든다면
  checkOnInstagram: "",
  sources: [{ label: "", url: "" }]
}
```
