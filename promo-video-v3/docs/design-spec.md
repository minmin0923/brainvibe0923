# 의정부혜택지도 홍보 영상 v3: 설계 문서

video-shotcraft **자주 자유 창작(autonomous)** 모드로 만든 세 번째 버전입니다. 0–3단계의 판단을 여기에 기록하고 그대로 제작했습니다.

## 0. 제품 브리프와 결정표

| 항목 | 결정 | 근거 |
|---|---|---|
| 용도 | 쇼츠·릴스·스토리 홍보, 가입 유도 | 사용자 요청 ("짧고 임팩트", CTA 유도) |
| 화면비·길이 | 9:16, 1080×1920, 30fps, 30초(900f) | v1·v2와 같은 세로형. 30초 안에 7개 장면 |
| 핵심 메시지 | 가입만 해도 가맹점 할인 / 가입 하나로 모든 혜택 / 의정부시민 누구나 / 지도에서 한눈에 / 계속 커지는 중 | 사용자 요청 1·2차 |
| CTA | 네이버카페에서 "의정부혜택지도" 검색 + 지금 가입하기 | 사용자 요청 2차 |
| 데이터 | 실제 가맹점명·할인율·가맹점 수 **쓰지 않음**. 업종 이름(카페, 음식점, 미용실, 생활)만 예시로 사용 | 확인된 공개 수치가 없음 |
| 실제 화면 | 의정부혜택지도 서비스 화면이 없어 화면 복제(Q1) 대상 없음. 모든 UI는 손으로 만든 비복제 구성요소 | Q1 |
| 음악 | 코드 합성(soundtrack 스킬 groove). BGM 판 + 효과음만 판 두 가지 | Freesound가 네트워크 정책으로 막혀 있음(403), BGM 후보 파일은 설치 때 제외됨 |

## 1. 시각 방향과 tokens

v2에서 사용자가 고른 "선명한 그린 + 옐로" 팔레트를 그대로 브랜드 기준으로 씁니다(영상 전용, DESIGN.md와 별개).

| token | 값 | 쓰임 |
|---|---|---|
| bg | `#F4FAF6` | 밝은 장면 바탕 |
| card | `#FFFFFF` | 카드, 알약 |
| line | `#DCE9E1` | 테두리, 지도 길 |
| ink | `#0E1A14` | 글자, 어두운 장면 바탕 |
| muted | `#4C5B53` | 보조 글자 |
| green | `#00A86B` | 면, 아이콘, 핀 |
| greenInk | `#00804F` | 글자로 쓰는 그린 |
| yellow | `#FFD43B` | 강조 띠, NEW, 버튼, 색 파도 첫 색 |

- 글꼴: Pretendard Variable 하나. 제목 800, 본문 600. 숫자는 tabular-nums.
- 움직임 성격: "친근한 지역 서비스"이므로 **亲和友好 프리셋**(주 동작 ~26f, bezier(0.25,0.46,0.45,0.94), 과충 1.04)에서 시작하고, 쇼츠라서 후킹과 마무리만 에너지를 올립니다.
- styleframe 생략: v1·v2 렌더본으로 색, 글꼴, 구도를 이미 사용자가 확인함.

## 2. 기능 → 샷 카드 매핑

| 기능/메시지 | 샷 카드 (demo 원본) | 고른 이유 |
|---|---|---|
| 후킹: 아직도 제값 다 내세요? | `lead-word-zoom-assemble` | "제값" 한 단어를 화면 가득 먼저 읽힌 뒤 문장이 조립됨 |
| 브랜드 첫인상 | `brand-ink-open` | 지도 조준선(십자) → 글자 압인 → 부제 타자 → 1초 정지 |
| 가입 하나로 모든 혜택 | `icon-field-colorize` | 업종 아이콘 키캡이 꺼진 채 깔렸다가 색 파도에 한 번에 켜짐 = 가입 한 번에 전부 열림 |
| 의정부시민 누구나 | `radial-wave` | 가운데에서 바깥으로 점(시민)이 차례로 켜짐 = 누구나 |
| 지도에서 한눈에 | `pill-slot-cycle` + 지도 핀 | "지도에서 찾는 [카페→음식점→미용실→생활]" 칸이 바뀔 때마다 그 업종 핀이 뜸 |
| 계속 커지는 중 | `crane-rise-reveal` | 새로 합류한 가게 한 곳 클로즈업 → 크레인처럼 올라가며 도시 전체 핀이 드러남 |
| CTA | `outro-group-photo-launch` + 검색창 타이핑 + 버튼 탭 | 앞 장면의 대표 요소가 사방에서 날아와 워드마크를 둘러싼 뒤 네이버카페 검색과 가입 버튼 |

한 가지 기법은 한 번만 주인공으로 씀(P4). 화면 전체 충격(scale 펌프, 흔들림)은 쓰지 않음(R4).

## 3. 스토리보드 (120 BPM, 1박 = 15f, 1마디 = 60f)

| # | 시간 | 프레임 | 샷 | 핵심 동작 | 자막 |
|---|---|---|---|---|---|
| S1 | 0–3.0s | 0–90 | lead-word-zoom-assemble | "제값" 2.3배 → 문장 조립, 부제 상승, 끝 12f crash | 의정부 사는 분, / **제값** 다 내세요? / 지금까지 받은 동네 할인 0원 |
| S2 | 3.0–6.5s | 90–195 | brand-ink-open | 십자 조준선 → 7글자 압인 → 부제 타자 → 1초 이상 정지 → 위로 사라짐 | 의정부혜택지도 / 의정부 동네 혜택을 지도 한 장에 |
| S3 | 6.5–11.5s | 195–345 | icon-field-colorize | 업종 키캡 120개 → 색 파도 4줄 → 가운데 어둠막 + 제목 | 가입 하나면 / 모든 혜택, 그냥 |
| S4 | 11.5–15.0s | 345–450 | radial-wave | 9×13 점이 가운데부터 켜짐, 두 번째 노란 펄스가 다시 모임 | 의정부시민이라면 / 누구나 / 복잡한 조건 없이, 가입 한 번이면 끝 |
| S5 | 15.0–20.0s | 450–600 | pill-slot-cycle | 4업종 알약 교체 + 업종별 핀, 마무리 "내 주변 가맹점." | 지도에서 찾는 / [카페·음식점·미용실·생활] → 내 주변 가맹점. |
| S6 | 20.0–24.0s | 600–720 | crane-rise-reveal | 새 가게 카드 3배 클로즈업 → 크레인 업 → 핀이 화면 가장자리 넘어올 때마다 켜짐 → 카드 "합류 완료" | 혜택지도는 / 계속 커지는 중 |
| S7 | 24.0–30.0s | 720–900 | outro-group-photo-launch + CTA | 7개 대표 요소 사방 비행 → 워드마크 압인 → 노란 선 → 네이버카페 검색 타이핑 → 가입 버튼 탭 → 1초 이상 정지 | 의정부혜택지도 / 자세한 혜택은 네이버카페에서 / 지금 가입하기 |

- 음악 구조: 0–22s 그루브, 22–24s 한 마디 브레이크(효과음만), 24s에 크래시와 함께 마지막 장면.
- 장면 경계는 모두 박(15f 배수)에 맞춤.

## 4. 일부러 다르게 한 것

- `pill-slot-cycle`: 카드 원본은 문장 끝 알약이 한 줄. 세로 화면이라 줄기를 첫 줄, 알약을 둘째 줄에 두고 둘 다 왼쪽 고정. 마무리 후 가운데 정렬 단계는 생략(왼쪽 정렬 레이아웃 유지).
- `radial-wave`: 카드는 어두운 배경을 요구. 브랜드 그린 `#00804F` 바탕에 연두 점 + 노란 펄스로 바꿈(점 대비 확보).
- `outro-group-photo-launch`: 카드는 outro에 자막을 넣지 않음. 이 영상은 CTA가 목적이라 워드마크 아래에 CTA 블록을 붙임. 금빛 먼지는 브랜드 옐로로 바꿈.
- 효과음: Freesound 대신 코드 합성 효과음(sound-design의 동작 어휘 whoosh, impact, click은 유지).
