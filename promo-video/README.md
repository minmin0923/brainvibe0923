# 의정부혜택지도 홍보 영상

- 완성본: `의정부혜택지도_홍보영상_9x16.mp4` (1080×1920, 30fps, 24초, 음악·효과음 포함)
- 미리보기: `index.html`을 브라우저로 열면 재생됩니다.

## 구성 (v2)

| 시간 | 장면 | 메시지 |
|---|---|---|
| 0–2.9초 | 후킹 | 의정부 사는 분, 아직도 **제값** 다 내세요? / 지금까지 받은 동네 할인 0원 |
| 2.8–5.6초 | 브랜드 | 지도에 길과 핀이 그려지고 "의정부혜택지도" 등장 |
| 5.5–9.6초 | 핵심 혜택 | 가입 하나면 모든 혜택, **그냥**. 가입 카드 → 업종별 혜택이 줄줄이 열림 |
| 9.6–12.8초 | 대상 | 의정부시민이라면 **누구나**. 복잡한 조건 없이, 가입 한 번이면 됩니다 |
| 12.8–16초 | 편의 | 내 주변 가맹점, 업종별로 지도에서 한눈에 |
| 16–19초 | 성장 | 혜택지도는 **계속 커지는 중**. 가맹점 점이 퍼지고 NEW 배지 |
| 19–24초 | CTA | 가입 하나로 의정부 혜택 전부 / 자세한 혜택은 네이버카페에서 "의정부혜택지도" 검색 / 지금 가입하기 |

## 다시 만들기

```bash
npm i playwright          # 또는 전역 설치된 playwright 사용
node audio.mjs            # out/audio.wav
node render.mjs           # out/video-silent.mp4 (프레임 단위 캡처)
ffmpeg -y -i out/video-silent.mp4 -i out/audio.wav -c:v copy -c:a aac -b:a 192k -shortest -movflags +faststart 의정부혜택지도_홍보영상_9x16.mp4
```

문구와 타이밍은 `index.html`의 `render(t)`와 `data-in` 값, 효과음 타이밍은 `audio.mjs`에서 고칩니다.
