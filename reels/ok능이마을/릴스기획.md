# 호원동 OK능이마을 릴스 기획

- 가게: OK능이마을 (의정부 호원동, 오리 요리 전문점, 동네 단골 맛집)
- 촬영 소스: 오리로스·주물럭 반반 구이 → 볶음밥 → 오리 해신탕 (짧게)
- 목표: 끝까지 보게 만들기, 저장·공유·태그 늘리기
- 길이: 26~30초 (9:16 세로, 컷 하나당 0.8~2초)

> 자막 통일 안내: 지난번 채선당 릴스 파일은 이 저장소와 노션 어디에서도 찾지 못했다.
> 그래서 아래 자막은 **역할(후킹 / 설명 / 강조 / 효과음)로만 나눴다.**
> 캡컷 등에서 채선당 때 저장해 둔 텍스트 프리셋을 같은 역할에 그대로 씌우면 통일된다.
> 채선당 영상의 폰트, 색, 위치를 알려 주면 이 문서의 값도 맞춰서 고친다.

---

## 1. 핵심 전략

| 장치 | 어디에 | 왜 |
|---|---|---|
| 첫 1초에 소리 + 결론 | 0초 | 불판 "치익" 소리와 반반 판을 먼저 보여 줘야 스크롤이 멈춘다 |
| 끝을 미리 약속 | 1~3초 | "마지막 볶음밥까지 보세요"로 끝까지 볼 이유를 만든다 |
| 2초마다 장면 전환 | 전체 | 집게로 뒤집기, 양념 떨어짐, 쌈 싸기처럼 손 동작이 있는 컷만 쓴다 |
| 볶음밥을 클라이맥스로 | 18~24초 | 누룽지 긁는 소리가 이 영상의 '돈 컷'이다. 가장 길게 쓴다 |
| 해신탕은 예고편 | 24~27초 | 다 보여 주지 않고 1.5초만. "다음 편"으로 팔로우 이유를 만든다 |
| 루프 엔딩 | 마지막 | 끝 컷이 첫 컷(불판)으로 자연스럽게 이어지게 해서 다시 보기를 유도한다 |

## 2. 컷 구성 (타임라인)

| 시간 | 화면 | 자막 (역할) | 소리 |
|---|---|---|---|
| 0.0–1.2 | 반반 불판 정면 위에서. 왼쪽 로스, 오른쪽 주물럭. 고기 올리는 순간 | **호원동 단골들만 아는 오리집** (후킹) | 치익 소리 크게, 음악 작게 시작 |
| 1.2–3.0 | 로스 고기 집게로 펼치기 클로즈업 | 로스 반 + 주물럭 반 = 고민 끝 (설명) / 끝에 볶음밥 있음 ⚠️ (강조, 작게) | 지글 |
| 3.0–5.0 | 로스 뒤집기, 기름 반짝임 | 생오리로스 (강조) | 뒤집는 소리 |
| 5.0–7.0 | 주물럭 양념이 불판에 닿으며 김 오름 | 매콤달달 양념 주물럭 (강조) | 치익 |
| 7.0–9.0 | 가위로 자르기 / 반반 판 전체 | 이 비주얼 실화? (효과음) | 가위 소리 |
| 9.0–12.0 | 로스 한 점 들어 올리기 (기름 떨어지는 슬로우 0.7배) | 기름 쫙 빠진 겉바속촉 (설명) | 음악 살짝 키움 |
| 12.0–15.0 | 쌈 싸기 → 한입 (먹는 사람 얼굴은 반만, 반응 위주) | 로스는 쌈, 주물럭은 밥도둑 (설명) | 씹는 소리(있으면) |
| 15.0–17.0 | 주물럭 양념 남은 불판 정리 | 근데 진짜는 지금부터 (후킹) | 음악 끊기 0.3초 |
| 17.0–21.0 | 밥, 김가루, 양념 붓고 볶기 | 남은 양념 = 볶음밥 재료 (설명) | 볶는 소리 |
| 21.0–24.0 | 불판에 눌러 누룽지 → 숟가락으로 긁기 (가장 긴 컷) | 바닥 누룽지 긁는 소리 🔊 (효과음) | 긁는 소리 최대 |
| 24.0–25.5 | 오리 해신탕 냄비 뚜껑 여는 순간 1.5초 | 그리고 이 집 숨은 메뉴… (후킹) | 보글 소리 |
| 25.5–28.0 | 해신탕 김 → 화면 어둡게 | 해신탕은 다음 편에서 👉 팔로우 (강조) | 음악 끝 |
| 28.0–29.0 | 첫 컷과 같은 구도의 빈 불판 → 1번 컷으로 이어짐 | 호원동 OK능이마을 📍 (설명) | 치익 (첫 컷과 연결) |

편집 팁
- 음악보다 **조리 소리가 주인공**이다. 음악은 20~30% 볼륨.
- 0.5초 이하 컷은 쓰지 않는다. 음식은 눈에 담길 시간이 필요하다.
- 전환 효과는 쓰지 말고 컷 편집만 한다. 동작이 이어지는 지점(뒤집기→뒤집기)에서 자르면 된다.
- 색은 따뜻하게(채도 +10, 색온도 살짝 높게). 기름 반짝임이 살아야 한다.

## 3. 자막 역할표 (채선당 프리셋을 여기에 맞춰 씌우기)

| 역할 | 쓰는 곳 | 크기 | 위치 | 등장 방식 |
|---|---|---|---|---|
| 후킹 | 첫 컷, "진짜는 지금부터", "숨은 메뉴" | 가장 큼, 두 줄 이내 | 화면 위쪽 1/3 | 팝업(튕기듯) |
| 설명 | 메뉴 설명 문장 | 중간 | 화면 아래쪽, 단 하단 UI(좋아요·캡션) 위 | 타자 또는 페이드 |
| 강조 | 메뉴 이름, 팔로우 | 중간, 강조 색 | 음식 바로 옆 | 확대 |
| 효과음 | "이 비주얼 실화?", "긁는 소리 🔊" | 작음, 기울임 | 화면 가운데 근처 | 흔들림 |

공통 규칙
- 한 화면에 자막은 한 줄(최대 두 줄), 14자 안팎.
- 자막이 음식을 가리지 않게 한다. 불판 정면 컷은 자막을 위로 올린다.
- 화면 오른쪽 아래(좋아요·댓글 버튼)와 맨 아래 15%(캡션)는 비워 둔다.

## 4. 캡션 (본문)

```
호원동 사는 사람들은 다 아는 그 오리집 🦆

로스 반, 주물럭 반 고민할 필요 없이 반반으로.
남은 양념에 볶음밥까지 긁어야 끝이에요 🍚

✔️ 생오리로스 + 양념주물럭 반반
✔️ 마지막 볶음밥 필수
✔️ 몸보신엔 오리 해신탕 (다음 편 공개)

📍 의정부 호원동 OK능이마을
🕒 영업시간: (확인 후 입력)
📞 예약: (확인 후 입력)

같이 갈 사람 태그 👇 저장해 두고 회식 때 꺼내 보세요

#의정부맛집 #호원동맛집 #의정부오리 #오리로스 #오리주물럭 #오리맛집 #해신탕 #볶음밥 #의정부회식 #몸보신 #OK능이마을
```

- 영업시간, 전화, 가격은 가게에 확인한 값만 넣는다. 추측해서 쓰지 않는다.
- 해시태그는 10~12개 안쪽으로. 지역(의정부·호원동) + 메뉴(오리) 조합이 핵심.

## 5. 참여(CTA) 장치

| 장치 | 내용 |
|---|---|
| 고정 댓글 | "로스파 vs 주물럭파? 댓글로 골라 주세요 👇" (선택형 질문은 답하기 쉬워 댓글이 많이 달린다) |

| 팔로우 유도 | 해신탕 예고 → "다음 편에서" |
| 커버 이미지 | 반반 불판 정면 + 큰 글씨 "호원동 오리 반반" (프로필 그리드에서 읽히게) |

## 6. 2편 (해신탕) 예고 활용

이번 영상 끝 1.5초를 2편 첫 컷으로 그대로 쓴다.
2편 첫 자막: **"지난번에 뚜껑만 보여 준 그 메뉴"** — 1편을 본 사람은 이어서 보고, 처음 본 사람은 1편으로 넘어간다.

## 7. 올리기 전 점검표

- [ ] 첫 1초에 불판과 소리가 바로 나온다 (로고, 가게 외관으로 시작하지 않는다)
- [ ] 자막이 하단 UI와 겹치지 않는다
- [ ] 자막 프리셋이 채선당 영상과 같다 (폰트, 색, 위치)
- [ ] 볶음밥 긁는 소리가 들린다
- [ ] 해신탕은 1.5초 이내로 짧다
- [ ] 영업시간, 전화, 가격을 가게에 확인했다
- [ ] 음악은 인스타그램 앱 안의 오디오(상업용 가능)로 넣었다
- [ ] 업로드는 점심 전(11시 전후)이나 저녁 전(17~18시)
